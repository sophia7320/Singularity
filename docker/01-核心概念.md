# Docker 核心概念

> 最后更新: 2026-05-12

---

## 关系链

```
Dockerfile ──docker build──▶ Image ──docker run──▶ Container
                                        │
                                   docker-compose.yml (编排多个容器)
```

## 概念表

| 概念 | 一句话 | 类比 |
|------|--------|------|
| 镜像 (Image) | 只读的应用安装包 | `.iso` 光盘镜像 |
| 容器 (Container) | 镜像运行起来的实例 | 用光盘启动的虚拟机 |
| Dockerfile | 描述如何构建镜像的文本 | `pom.xml` 定义如何构建项目 |
| Docker Compose | 编排多个容器一起运行 | 一键启动 MySQL + Redis + 应用 |
| 镜像仓库 (Registry) | 存放和分发镜像 | Maven 中央仓库 / GitHub |
| 卷 (Volume) | 持久化容器数据 | 外挂硬盘 |
| 网络 (Network) | 容器间通信 | 虚拟局域网 |

## 多阶段构建

```
阶段一 (builder):      阶段二 (runtime):
┌────────────────┐     ┌────────────────┐
│ maven:3.9-jdk17 │     │ temurin:17-jre │
│                 │     │  (只有 JRE)    │
│ COPY pom.xml    │     │                │
│ mvn package     │     │ COPY JAR       │
│         ↓       │     │   ↑           │
│  生成 app.jar ──│──copy──┘             │
└────────────────┘     └────────────────┘
      ~450MB               ~180MB
```

> 编译阶段用完整 JDK，运行阶段只保留 JRE，最终镜像缩小一半以上。
