# 调试与排错

> 最后更新: 2026-05-12

---

## 一、调试命令

### 查看详情

```bash
docker inspect container-name
```

> 容器 IP、挂载、环境变量等

### 资源监控

```bash
docker stats
```

> 实时 CPU / 内存占用

### 磁盘占用

```bash
docker system df
```

> Docker 磁盘占用总览

### 清理

```bash
docker system prune -a
```

> 清理所有未使用的镜像/容器/网络/缓存（慎用！）

---

## 二、常见问题

### 容器启动立即退出

```bash
docker logs container-name
```

> 查看退出前日志定位原因

### 端口冲突

```
Error: port is already allocated
```

→ 改宿主机端口（左边那个数字）

### MySQL 8.0 编码报错

```
Unsupported character encoding 'utf8mb4'
```

→ JDBC URL 中 `characterEncoding=utf8mb4` 改为 `characterEncoding=UTF-8`

### 容器间连不上

→ 用服务名（如 `mysql`、`redis`）而非 `localhost`  
`localhost` 永远指向容器自己
