# 安装（Arch Linux）

> 最后更新: 2026-05-12

---

## 安装

```bash
sudo pacman -S docker docker-buildx docker-compose
```

## 启动服务

```bash
sudo systemctl enable --now docker
```

## 免 sudo

```bash
sudo usermod -aG docker $USER
```

> 重新登录后生效

## 验证

```bash
docker run hello-world
```

> 看到 `Hello from Docker!` 即成功
