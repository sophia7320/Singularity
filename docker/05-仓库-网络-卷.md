# 仓库、网络与卷

> 最后更新: 2026-05-12

---

## 一、镜像仓库

### 登录

```bash
docker login
```

> Docker Hub

---

**腾讯云：**

```bash
docker login ccr.ccs.tencentyun.com --username=腾讯云账号ID
```

> 密码用 API 密钥或控制台生成的临时密码

### 推送

```bash
docker tag local-image:latest registry.example.com/ns/image:v1
```

---

```bash
docker push registry.example.com/ns/image:v1
```

### 拉取

```bash
docker pull image-name:tag
```

### 登出

```bash
docker logout registry.example.com
```

---

## 二、网络

### 查看

```bash
docker network ls
```

---

```bash
docker network inspect bridge
```

---

## 三、卷

### 查看

```bash
docker volume ls
```

### 删除

```bash
docker volume rm volume-name
```

### 清理

```bash
docker compose down -v
```

> 停止服务并删除关联卷

---

## 端口映射

```
"宿主机端口:容器端口"

例: "3307:3306"
  宿主机 localhost:3307 → 容器内 mysql:3306
  容器间通信 mysql:3306 不受影响
```
