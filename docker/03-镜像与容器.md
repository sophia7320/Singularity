# 镜像与容器操作

> 最后更新: 2026-05-12

---

## 一、镜像操作

### 构建

```bash
docker build -t image-name:tag .
```

> `-t` 命名标签 | `.` 构建上下文目录

---

**指定 Dockerfile：**

```bash
docker build -t myapp -f path/to/Dockerfile context-dir
```

### 查看

```bash
docker images
```

---

```bash
docker images | grep keyword
```

### 删除

```bash
docker rmi image-name:tag
```

---

```bash
docker rmi image-id
```

### 标签

```bash
docker tag local-image:latest registry.example.com/namespace/image:v1
```

### 导出入

```bash
docker save image-name:latest -o image.tar
```

---

```bash
docker load < image.tar
```

---

## 二、容器操作

### 启动

```bash
docker run -d --name my-container -p 8080:8080 image-name
```

> `-d` 后台 | `--name` 命名 | `-p 宿主机:容器`

---

```bash
docker run -d -p 8080:8080 -e SPRING_PROFILES_ACTIVE=dev image-name
```

> `-e` 环境变量

---

```bash
docker run --rm -p 8080:8080 image-name
```

> `--rm` 停止后自动删除

### 查看

```bash
docker ps
```

> 运行中

---

```bash
docker ps -a
```

> 全部（含已停止）

### 日志

```bash
docker logs container-name
```

---

```bash
docker logs -f container-name
```

> `-f` 实时跟踪

---

```bash
docker logs --tail 50 container-name
```

### 进入

```bash
docker exec -it container-name sh
```

> Alpine 用 `sh`

---

```bash
docker exec -it container-name bash
```

> Ubuntu/Debian 用 `bash`

### 控制

```bash
docker stop container-name
```

---

```bash
docker start container-name
```

---

```bash
docker restart container-name
```

### 删除

```bash
docker rm container-name
```

---

```bash
docker rm -f container-name
```

> `-f` 强制（运行中也删）
